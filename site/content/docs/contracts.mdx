<PlainWords>

Turn is made of a handful of small programs, called contracts, on the Monad blockchain. Their code is public, and anyone can read what they do.

This page lists where each one lives on each network, with links to see them on a block explorer.

</PlainWords>

## Addresses

<ContractAddresses />

The table is built from `contracts/deployments/<chainId>.json`, written by the deploy script (`Deploy.s.sol`). The docs never contain hand-typed addresses, so they can't drift from what is actually deployed.

## Contracts

| Contract | What it does | Source |
| --- | --- | --- |
| `CircleFactory` | Creates circles as EIP-1167 clones, keeps the registry of real circles, enforces beta caps, and can pause creating and joining | <Source path="contracts/src/CircleFactory.sol" /> |
| `Circle` | One per group: rounds, sealed-bid auction, collateral, reserve, defaults, ejection, settlement | <Source path="contracts/src/Circle.sol" /> |
| `CreditRegistry` | Non-transferable payment records and `score(address)` | <Source path="contracts/src/CreditRegistry.sol" /> |
| `TrustMath` | Pure library: `score(record)` and `trustBps(record)` | <Source path="contracts/src/libraries/TrustMath.sol" /> |
| `TurnAccount` | EIP-7702 delegate: EIP-712 signed batches and contract-enforced auto-pay | <Source path="contracts/src/TurnAccount.sol" /> |
| `TurnKeeper` | Chainlink CRE receiver that calls permissionless round functions | <Source path="contracts/src/TurnKeeper.sol" /> |
| `MockAUSD` | Test token with a capped faucet. Testnet and local only | <Source path="contracts/src/test-tokens/MockAUSD.sol" /> |

ABIs are exported from the Foundry build into `contracts/abi/` (`pnpm abi`) and shared through the `@turn/contracts` workspace package, so the app, relayer and keeper all use the same ones.

<Callout title="Changed from the first plan">

`docs/plan.md` first described open bids (`bid(uint16)` with a `BidPlaced` event). Turn now uses sealed commit–reveal bids (see [Bidding](/docs/bidding)), so `commitBid(bytes32)` and `revealBid(uint16, bytes32)` replace `bid`, and `BidCommitted` and `BidRevealed` replace `BidPlaced`. Swapping turns (`proposeSwap(address)` and `acceptSwap(address)`, with `SwapProposed` and `TurnsSwapped`) is also new. See [Onchain, precisely](/docs/onchain#every-action-as-a-transaction).

</Callout>

## Deployment file format

```json title="contracts/deployments/10143.json"
{
  "chainId": 10143,
  "factory": "0x…",
  "circleImplementation": "0x…",
  "registry": "0x…",
  "accountImplementation": "0x…",
  "keeper": "0x…",
  "creForwarder": "0x…",
  "token": "0x…",
  "mockToken": true,
  "owner": "0x…",
  "startBlock": 65859276
}
```

The network name and block explorer come from the chain ID. `startBlock` is where the indexer begins, and `31337.json` (the local anvil chain) is never shown.
