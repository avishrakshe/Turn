Static TTF instances used only by `next/og` (OG image rendering), which can't read woff2.
The site itself loads these families through `next/font/google`.

- `Fraunces-SemiBold-Soft.ttf`: Fraunces (opsz 144, wght 600, SOFT 100), SIL Open Font License 1.1
- `DMSans-Medium.ttf`: DM Sans (wght 500), SIL Open Font License 1.1

Source: Google Fonts.
